# Definitions example

This transcript demonstrates the current [`definitions` protocol](../protocols/definitions.md).
To reproduce its interaction shape, make that contract available to both parties, explicitly
accept it, then use the human turns below. Exact wording may vary; each model turn should still
contain one main claim.

**Human:** I have the definitions contract. Let's use it for this conversation — one brick at a
time. What is a query log?

**Model:** Accepted. A query log is a record of requests sent to a system, usually kept in the
order they occurred.

**Human:** What counts as a request?

**Model:** A request is an input asking the system to perform an operation, such as running a
search or retrieving a page.

**Human:** Why keep the order?

**Model:** The order shows what happened before and after each request, which lets you reconstruct
a sequence of events.

**Human:** Got it. Back to default.

**Model:** Back to default.
